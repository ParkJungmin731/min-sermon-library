# 실제 모델 품질 검토

cases.json의 20개 요청을 선택한 실제 모델·프롬프트 버전으로 실행한 뒤 review-template.csv에 결과를 기록합니다. 지금 포함된 파일은 평가 도구이지 성능 달성 결과가 아닙니다.

1. 한 사례씩 입력하고 전송 동의를 확인합니다. 유료 호출은 운영 계정의 한도 안에서 진행합니다.
2. 형식 통과, 본문 문맥 충실성·구어체·적용(각 1~5), 허위 인용 건수를 목회자가 평가합니다.
3. 모델·프롬프트 버전·토큰·응답 시간을 기록합니다. 단가는 해당 모델의 현재 요금을 확인한 후 계산합니다.
4. 초기 목표: 형식 95% 이상, 본문 충실성 평균 4/5 이상. 허위 인용이 있으면 수정 전 사용하지 않습니다.
5. API 거절·잘린 응답·서버 오류는 자동 테스트에서 별도로 확인합니다. 실제 초안 품질은 모의 응답 테스트로 입증되지 않습니다.
6. 출처 검색 AI는 일반 검색의 실패 질문을 모은 후 승인 자료에 한해 도입 여부를 결정합니다.
